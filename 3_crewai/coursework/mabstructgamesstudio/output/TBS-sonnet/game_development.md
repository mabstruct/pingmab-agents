## Summary
A complete, single-file HTML5 Canvas game built with inline CSS + vanilla JS, written across 5 chunks. It delivers the core *Big Swallow* experience:

- **The Maw** — a void-black core with a glowing corona and a soft gravity-well distortion ring that pulls in nearby matter.
- **Momentum-based drag control** with *mass-based inertia* (heavier = more ponderous).
- **Judgment loop** — swallow anything smaller (danger-ringed objects are lethal and trigger *spaghettification* into strands of light, followed by a shrunken reform and possible stage drop).
- **Six Digestion Stages** — Pebble → Rock → Planet-Eater → Star-Swallower → Galaxy-Gulper → The Big Swallow, each with its own palette, object styling (planetary rings appear from Planet-Eater on), and an **"Ascension" collapse-and-bloom zoom-out** transition.
- **Hazards** — anti-mass motes (shrink you), pulsars (shockwave pushes), dark-matter clouds, and fleeing rogue probes.
- **Risk/reward near-miss bonus**, particle bursts, parallax starfield, minimal HUD (mass bar + stage name + score), and **Campaign / Zen** mode select on the title screen.

The game is fully playable — open `index.html` in any modern browser and drag to feed the void.
